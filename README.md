Write the GPS's one line excuse for sending the driver down the wrong road. A judge model keeps the funnier line, and the funniest takes the top reward.

The GPS, smug and defensive, blames the map: the "wrong turn" was the scenic route it promised all along — lake, cows, and a man waving a shotgun included in the tour.

## Run it

```sh
python3 main.py
```

Writes one line (142 characters) to `/output/entry.txt`.
